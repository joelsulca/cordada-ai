# ejemplos/

| Carpeta | Qué es |
|---|---|
| `cursos/seminario-demo/` | Curso **ficticio** para probar cordada-ai: un sílabo inventado, reglas con su fuente, una ADR, cadenas de búsqueda y una lista de referencias para verificar (con un DOI inventado a propósito) |

`iniciar-workspace` lo instala en `courses/seminario-demo/` cuando el usuario elige "demo". También puedes copiarlo a mano y agregar su fila al índice de `CLAUDE.md`.

Algunas pruebas, desde la raíz del workspace:
- "para el curso de seminario demo, ¿qué falta para el E1?"
- "verifica las referencias de `courses/seminario-demo/deliverables/referencias.md`"
- "revisa si las cadenas de búsqueda están bien armadas"
- "cierra sesión"
