# perfil/

Aquí vive el perfil de **tu** workspace. Lo crea el skill `iniciar-workspace` la primera vez que abres el workspace con un agente.

| Archivo | Qué contiene |
|---|---|
| `perfil.md` | Universidad, normas académicas, forma de trabajo (individual o equipo) e integrantes |
| `citacion-local.md` | *(opcional)* En qué difiere la guía de citación de tu universidad del estándar, con su fuente |
| `referencia/` | *(opcional)* Datos de referencia que usan los skills, como el CSV anual de SCImago (`scimagojr <año>.csv`) |
| `skills/` | *(opcional)* Skills propios de tu universidad, como el formato de un acta |

En la plantilla pública esta carpeta está vacía a propósito: cada persona arma la suya. Si quieres ver un perfil completo, mira `perfiles-ejemplo/upc/`.
