# Perfil de ejemplo: UPC

Perfil institucional de muestra con la **Universidad Peruana de Ciencias Aplicadas (UPC)**, de Lima, Perú. Lo usa `iniciar-workspace` cuando alguien elige **"demo"**, y sirve como modelo para armar el perfil de cualquier otra universidad.

> **cordada-ai no está afiliado a la UPC ni cuenta con su respaldo.** Este perfil usa solo información pública (la guía de citas de su biblioteca) y no incluye material de cursos, logos, nombres de docentes ni documentos internos.

| Archivo | Qué muestra |
|---|---|
| `perfil.md` | Un perfil completo: institución, normas, forma de trabajo |
| `citacion-local.md` | Cómo registrar las diferencias entre la guía de una biblioteca y el estándar APA 7, cada una con su fuente |
| `skills/generar-acta-asesoria/` | Un skill propio de una universidad: genera el acta de una asesoría a partir del acta anterior y de los apuntes que envía el docente |

Para tu universidad, copia esta carpeta como guía, pero llena los datos con tu propia fuente. No reutilices las diferencias de citación de la UPC.
